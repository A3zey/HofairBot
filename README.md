# بوت توصيات تداول لتلقرام (نسخة تجريبية بيانات وهمية)

## أهم نقطة قبل أي شي
هذا البوت **لا يضمن دقة ولا ربح**. أي بوت أو إنسان يوعدك بـ"أدق من كل البشر"
أو "أفضل متداول في العالم" يسوّق كذب. خليت التنويه القانوني (`DISCLAIMER_AR`
في `config.py`) يظهر تلقائيًا بكل بطاقة توصية — لا تحذفه، خصوصًا إنك بتوزعه
على قناة فيها متابعين ممكن يتخذون قرارات مالية حقيقية بناءً عليه.

## شنو مبني فعليًا
- `data_source.py` — حاليًا بيانات **وهمية** (mock) تتحرك بمشية عشوائية،
  عشان تقدر تجرب شكل البوت بدون اشتراك API. فيه هيكل جاهز (`RealDataSource`)
  تعبيه لاحقًا ببيانات حقيقية.
- `strategy.py` — استراتيجية مثال بسيطة (تقاطع متوسطين متحركين + RSI).
  **مو استراتيجية مضمونة** — عدّلها أو استبدلها حسب منهجك الخاص.
- `card_generator.py` — يرسم بطاقات صور احترافية (Pillow) فيها اسم السهم،
  الدخول، وقف الخسارة، الأهداف، وبطاقة منفصلة لما يتحقق هدف.
- `signal_tracker.py` — يتابع كل توصية مفتوحة ويكتشف تلقائيًا لما يتحقق
  هدف أو ينضرب وقف الخسارة.
- `bot.py` — يشغّل الحلقة الكاملة ويرسل الصور لقناتك على تلقرام.

## خطوات التشغيل

### 1) تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2) تحميل خط عربي (مهم جدًا)
النصوص العربية بالصور تحتاج خط حقيقي يدعم العربي، وإلا بترسم بشكل مكسور.
نزّل خط **Noto Naskh Arabic** مجانًا من Google Fonts:
https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic

حط الملفين هنا:
```
fonts/NotoNaskhArabic-Regular.ttf
fonts/NotoNaskhArabic-Bold.ttf
```

### 3) إنشاء بوت تلقرام
- كلم [@BotFather](https://t.me/BotFather) على تلقرام
- أرسل `/newbot` واتبع التعليمات، بترجع لك **توكن**
- ضيف البوت كـ Admin في قناتك حتى يقدر ينشر فيها

### 4) تعبئة الإعدادات
```bash
export TELEGRAM_BOT_TOKEN="التوكن_اللي_عطاك_BotFather"
export TELEGRAM_CHANNEL_ID="@اسم_قناتك"
```
أو عدّلهم مباشرة في `config.py`.

### 5) التشغيل
```bash
python bot.py
```
البوت بيفحص الرموز في `WATCHLIST` كل `PRICE_CHECK_INTERVAL_SECONDS` ثانية،
وإذا لقى إشارة يرسل بطاقة توصية، وإذا تحقق هدف أو انضرب وقف خسارة يرسل تحديث.

## الانتقال من بيانات وهمية إلى بيانات حقيقية
غيّر في `config.py`:
```python
DATA_SOURCE_MODE = "real"
```
وبعدين اربط `RealDataSource` في `data_source.py` بأحد هذي المزوّدين
(كلهم عندهم خطة مجانية محدودة تكفي للتجربة):
- Alpha Vantage — https://www.alphavantage.co
- Twelve Data — https://twelvedata.com
- Finnhub — https://finnhub.io

## للاستمرارية بين التشغيلات
حاليًا `signal_tracker.py` يحتفظ بالصفقات المفتوحة بالذاكرة فقط — إذا
أوقفت البوت وشغلته من جديد بينسى الصفقات المفتوحة. لو محتاج استمرارية
حقيقية (يستحسن لقناة فيها متابعين)، حوّل `SignalTracker` لتخزين بـ SQLite
بدل القائمة بالذاكرة — قولي إذا تبيني أضيفها.

## قبل ما توزعه على متابعين فعليين
1. اختبره أسابيع بالبيانات الوهمية أو ببيانات حقيقية بدون نشر فعلي، وشوف
   جودة الإشارات.
2. لا تسوّقه بأي وعد دقة أو أرباح مضمونة — فيه أنظمة وقوانين بعض الدول
   تجرّم هذا النوع من التسويق المالي المضلل.
3. خلي التنويه ظاهر دائمًا وواضح.
